# Decision — keep the transformed-hero bounty as risk/reward

- **Decision:** a transformed hero is worth more gold when killed. This is kept, framed as **risk/reward for the transformed player**: the form makes them stronger, but they're a more valuable target while it lasts.
- **Context:** the transformation spec recommended a higher bounty on transformed heroes (about 1.5–2× base) and described it as "a comeback lever". The owner had ruled out comeback mechanics. The bounty is kept with the risk/reward framing instead, so it rewards whoever takes on the strongest enemy rather than helping a losing team.
- **Prototype values (placeholders until enemy heroes exist):** base hero bounty 300 gold; ×1.75 while transformed (525), the midpoint of the spec's 1.5–2× range. The current bounty is shown on the HUD so the player can see the risk.
