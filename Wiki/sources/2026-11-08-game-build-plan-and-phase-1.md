# Game build plan and Phase 1

The owner asked for a full Android game keeping the map's nostalgic feel. The plan builds the same kind of game with original content — not copies of the map's characters, skills, icons, map or Blizzard's UI — in five phases. Phase 1 delivered the main menu, settings, hero select by category and an in-game pause menu, verified on the phone.

## Key points
- **Scope line:** same mechanics and classic fantasy-RTS feel, original characters/skills/icons/items/map/UI art; no replicas of the map's content or Blizzard's UI; "FZFoC" kept as a working title.
- **Phases:** 1 menus and settings · 2 single player vs adaptive AI on an original arena · 3 item shop by category · 4 local Wi-Fi play · 5 heroes 2–3, icons, audio.
- **Phase 1:** main menu (Single Player · Play with Friends · Settings · Quit); hero select with Bruiser/Speed/Giant tabs and locked planned slots; audio and video settings saved to the device; pause menu (Resume · Settings · Quit to Menu · Quit Game); Android back supported.
- **Verification:** menu-flow test 10/10, all suites pass, phone walkthrough; hero-select overflow found on the phone and fixed.
- **Observation:** ~15 s first launch on the phone (shader compilation).
