# Asset Credits

Every third-party asset used in the game. Add a row the moment you download something — before importing it.

## How to fill it in
- **ID:** short code you can use in filenames or notes (`ENV-001`, `CHR-001`, `PRP-001`, `SFX-001`, `MUS-001`).
- **Licence:** copy it exactly from the model page: `CC0`, `CC BY`, `CC BY-SA`, `CC BY-NC`, `CC BY-ND`, `Editorial`.
- **Modified?:** `No`, or what you changed (rigged, retextured, polygons reduced, recoloured). Changing a `CC BY-ND` asset isn't allowed.
- **Status:** `OK` · `Check` (licence unclear) · `Replace` (can't be used — ND needing changes, Editorial, or fan art of an existing character).
- Save a screenshot of each licence section in `licences/` named after the ID, in case the page changes or disappears.

## Licence quick check
| Licence | Use in game | Credit required | Can modify | Can sell |
|---|---|---|---|---|
| CC0 | ✅ | No | ✅ | ✅ |
| CC BY | ✅ | Yes | ✅ | ✅ |
| CC BY-SA | ✅ | Yes | ✅ (share changes under same licence) | ✅ |
| CC BY-NC | ✅ | Yes | ✅ | ❌ |
| CC BY-ND | ⚠️ only unchanged | Yes | ❌ | ✅ |
| Editorial | ❌ | — | — | — |
